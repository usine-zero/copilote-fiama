# BUILD 33 — Sécurité dictée / envoi

- Le bouton CONTINUER/ENVOYER est désactivé pendant une dictée active.
- Empêche l’envoi accidentel d’une transcription partielle pendant que Fiama parle.
- Après arrêt/fin du micro, le bouton est réactivé et la phrase reste à vérifier avant envoi.
- Garde supplémentaire côté gestionnaire ENVOYER si une reconnaissance est encore active.
- Cache PWA et métadonnées synchronisés sur BUILD 33.
- Aucun fournisseur IA payant ni secret client ajouté.
