# BUILD 39 — restauration défensive

- Validation renforcée du fichier de sauvegarde avant toute modification locale.
- Refus d'un profil de type inattendu, d'une langue inconnue ou de préférences mal formées.
- Limite de taille appliquée au profil restauré.
- Une sauvegarde invalide ne modifie aucune donnée.
- Versions client, cache et passerelle synchronisées sur BUILD 39.
