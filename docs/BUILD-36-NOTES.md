# BUILD 36 — restauration réversible

- Avant toute restauration de sauvegarde, COPILOTE FIAMA conserve localement un instantané des données présentes.
- Un bouton « Annuler la dernière restauration » apparaît ensuite dans l’espace sauvegarde.
- L’annulation restaure mémoire, profil, langue et préférences locales précédentes.
- Aucune donnée n’est envoyée à un serveur par ce mécanisme.
- Version active synchronisée sur BUILD 36.
